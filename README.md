## About WishCraft

WishCraft is an interactive digital keepsake builder designed to replace disposable, static greeting cards with immersive, cinematic multi-chapter web experiences.

Every experience crafted on WishCraft is a bespoke interactive gift featuring:
- **Interactive Security Vaults**: Simulated biometric fingerprint scanners, frosted glass scratch reveals, and secret passcode decryption.
- **3D WebGL Particle Engines**: Liquid gold particle fields, floating embers, and GPU-driven canvas interactions powered by Three.js.
- **Personalized Memory Carousels**: Custom photo galleries and interactive polaroid carousels.
- **Curated Flagship Editions**:
  - *Royal Velvet Premiere*: An opulent royal gold and velvet celebration experience.
  - *Obsidian Vault // Liquid Gold Edition*: A 6-chapter dark obsidian experience featuring 3D tilt cards, liquid biometric scanner, frosted glass scratch reveal, 10-memory carousel, infinity clock, and 6-digit decryption vault.
- **Instant Cloud Publishing**: One-click publication to secure cloud storage with personalized shareable links and QR codes.

---

## Technical Architecture

- **Frontend**: Vanilla JavaScript (ES Modules), CSS Custom Properties, and responsive Glassmorphism design without external framework overhead.
- **Visuals & 3D**: Three.js, HTML5 Canvas 2D, WebGL.
- **Soundscapes**: Web Audio API synthesized pentatonic luxury chimes.
- **Backend & Cloud**: Express.js server, Netlify Serverless Functions, and Firebase Firestore / Auth.
- **Deployment**: Netlify ([https://wishcraft-12.netlify.app/](https://wishcraft-12.netlify.app/)).

## Local Development

```bash
# Clone repository
git clone https://github.com/yashjare900-boop/Wishcraft-12.git
cd Wishcraft-12

# Install dependencies
npm install

# Configure environment variables
# Copy .env.example to .env and configure your GEMINI_API_KEY
cp .env.example .env

# Run local development server
npm start
# Server opens at http://localhost:3000
```
