✦ What is WishCraft?

WishCraft is a creative web project created and developed by Yash Jare. It bridges emotional sentiment with state-of-the-art web technology, allowing anyone to craft interactive, multi-chapter gift experiences for birthdays, anniversaries, milestones, and meaningful celebrations.

Instead of a standard static web page or template, every WishCraft creation functions as a living interactive journey: complete with biometric touch verification, frosted glass scratch reveals, synchronized 3D WebGL particle simulations, ambient soundscapes, memory carousels, and encrypted vault finales.

🔐 Security Vaults
Biometric fingerprint simulation, frosted scratch cards, and passcode-protected chapters that build wonder and anticipation.
🌌 3D WebGL & Canvas
Silky smooth Three.js particle simulations, ambient floating embers, and GPU-driven animations tailored to every theme.
📱 Device Agnostic
Responsive layouts fine-tuned across mobile smartphones, tablets, and high-resolution desktop displays.

✦ Technical Architecture

Architected and built from the ground up by Yash Jare, WishCraft leverages vanilla standards-compliant web technologies for lightning-fast load times and zero framework bloat:

• Frontend Engine: High-fidelity CSS Glassmorphism, CSS Custom Properties, and responsive flex/grid layouts crafted without heavyweight dependencies.

• Interactive Canvas & WebGL: Custom GPU-accelerated delta-timing engines for smooth gesture handling and Three.js 3D rendering.

• Cloud & Serverless Infrastructure: Hosted on Netlify with serverless functions and Firebase Firestore for instant one-click publication and secure sharing.
